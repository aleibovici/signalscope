# Security Policy

## Reporting a vulnerability

Please report security issues **privately** using GitHub Security Advisories for this repository:

https://github.com/aleibovici/signalscope/security/advisories/new

Do **not** open a public GitHub Issue for vulnerabilities or leaked secrets.

There is no project support mailbox. Maintainer communication for security reports is through GitHub only.

## Supported versions

Security fixes are applied on a best-effort basis to the default branch (`main`).

## Self-hosted deployments

If you operate your own SignalScope instance, you are responsible for securing your host, database, secrets, and reverse proxy. Rotate any credentials that may have been exposed.
